# Contributing Guide

## Branching Strategy

- main: production, protected
- develop: integration branch
- feature/*: new features
- hotfix/*: urgent fixes

## Commit Convention

Format: type(scope): description

Types: feat, fix, docs, chore, refactor, ci

Example: feat(terraform): add hub-spoke peering for canadaeast

## Pull Request Requirements

1. Pass all CI checks
2. One peer review minimum
3. Updated documentation if architecture changes
4. Reference a GitHub issue
